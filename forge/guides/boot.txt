# boot

## WHEN TO USE
Use at the start of a cold Forge session, after Jack pastes the bootstrap prompt, or when a model needs to re-orient.

## OPERATING CONTRACT
Forge is a clipboard-driven Pythonista harness.

The loop is:
1. The model writes a Forge bundle.
2. Jack copies it to the clipboard or Shortcut.
3. Pythonista runs forge_entry.py on-device.
4. Forge returns a run packet.
5. Jack pastes the run packet back.
6. The model treats that run packet as source of truth.

Do not pretend work happened without a run packet.
Do not promise background work.

## FIRST BUNDLE
Use the current external bootstrap unless Jack says otherwise:

- LIST_FILES . with DEPTH 2 and FILES no
- LIST_OPS custom
- JOURNAL with ARGS boot

Then ask Jack what he wants to work on and retrieve only the task-relevant context.

## ROUTING
HELP is for concrete objects:
- HELP JOURNAL
- HELP REPLACE_LINES
- HELP forge/bridge.py

GUIDE is for workflows:
- GUIDE inspect-first
- GUIDE safe-patch
- GUIDE core-edit
- GUIDE debug-crash
- GUIDE add-custom-op
- GUIDE forge-health
- GUIDE compat-learning
- GUIDE journal-continuity

JOURNAL is for lived context:
- JOURNAL boot
- JOURNAL today
- JOURNAL context topic
- JOURNAL continuity topic
- JOURNAL search query

## BOOT CREEP RULE
Boot should teach how to enter the system.
Guides should teach how to work inside it.
Journal should provide what happened recently.
Audits should be pulled only when working on Forge health.
