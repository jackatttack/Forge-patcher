# custom-ops

## WHEN TO USE
Use when a repeated workflow deserves its own Forge command.

## SUMMARY
Core Forge should stay small. Personal workflows belong in custom ops.

## LOCATION

    forge/ops/custom/

Enable custom ops in:

    forge/config.py

Change:

    LOAD_OP_LAYERS = ['core']

to:

    LOAD_OP_LAYERS = ['core', 'custom']

Then run:

    REFRESH

## MINIMAL OP SHAPE
A custom op should define:

- SPEC
- optional HELP
- optional HINTS
- validate(parsed_op)
- execute(ctx, parsed_op, result)

## DESIGN RULE
Keep custom ops thin. Put reusable logic in normal Python modules and let the op wrap it.

## GOOD USE CASES
- Project test runner
- App launcher
- API wrapper
- File exporter
- Personal workflow command
- Dataset search
- Deployment helper
