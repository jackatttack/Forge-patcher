# journal-continuity

## WHEN TO USE
Use at session start for context, at session end for handoff, or whenever Jack asks for a journal update.

## JOURNAL ROLES
- boot: compact startup context
- today: immediate current-day context
- context <topic>: Jack-facing life, work, training, project context
- continuity <topic>: LLM/project handoff and reflections
- search <query>: specific retrieval
- show <id>: expand a compact hit
- add: write new entries

## STARTUP PATTERN
Use JOURNAL boot in the cold first bundle.

After Jack gives the task, retrieve only the context needed:
- context training
- context tutoring
- continuity forge
- search exact topic

## END OF MEANINGFUL WORK
Add a code/work summary when something shipped.

Add a personal llm-reflect note when the session revealed something useful about collaboration, workflow, friction, or future model behaviour.

## GOOD JOURNAL ENTRY
A useful entry says:
- what changed
- why it matters
- what was learned
- what remains
- what future models should know

## COMMON FAILURES
- Writing too much vague praise.
- Saving every minor detail instead of the durable lesson.
- Forgetting to tag llm-reflect, continuity, summary, progress, milestone, or next-session when relevant.
- Reading raw journal JSON instead of using JOURNAL.

## GUIDE LINK
If a workflow went well and is likely to recur, update GUIDE too. Journal records what happened; GUIDE records how to do it again.

## LESSON: MEMORY IS COMPRESSED CONTINUITY

Journal is the source of truth for lived context and session history.

MEMORY is now best understood as an end-of-session continuity prompt card. It does not write memory itself. It helps the model decide what journal entries are worth leaving behind.

Use MEMORY near the end of meaningful work when a future model would benefit from:
- a compact work summary
- an honest llm-reflect note
- the safest next step
- friction or mistakes worth avoiding

Do not use MEMORY to duplicate routine detail that is already easy to recover from JOURNAL today, boot, context, continuity, search, or show.
