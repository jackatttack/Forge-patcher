# tutorial-files

## SUMMARY
Learn safe file operations in Forge using a scratch tutorial folder. You will create a file, preview it, run it, edit it, move it, and clean up.

## WHEN TO USE
Use this after [[tutorial-loop]] when you are ready to try harmless write operations.

## SAFETY
This tutorial only writes inside:

    scratch/forge_tutorial/

That folder is safe for learning.

## GOAL
Learn these ops:

- CREATE_FILE
- PREVIEW
- RUN_FILE
- REPLACE_FILE
- MOVE_FILE
- DELETE_FILE

## STEP 1 — CREATE A FILE
Copy and run this bundle.

    @forge-bundle tutorial-files-create
    CREATE_FILE scratch/forge_tutorial/hello.py
    BEGIN_BODY
    print("Hello from Forge")
    END_BODY
    @end-forge-bundle

## EXPECT
The packet should show:

    APPLIED | CREATE_FILE | scratch/forge_tutorial/hello.py

Forge creates parent folders automatically if needed.

## STEP 2 — PREVIEW THE FILE
Preview reads the file without running it.

    @forge-bundle tutorial-files-preview
    PREVIEW scratch/forge_tutorial/hello.py
    LINES: 1-20
    @end-forge-bundle

## EXPECT
The packet should show the file contents with line numbers.

## STEP 3 — RUN THE FILE
Run the Python file and capture its output.

    @forge-bundle tutorial-files-run
    RUN_FILE scratch/forge_tutorial/hello.py
    @end-forge-bundle

## EXPECT
The packet should show:

    exit 0
    Hello from Forge

If you see exit 0, the file ran successfully.

## STEP 4 — REPLACE THE FILE
Now change the file contents.

    @forge-bundle tutorial-files-replace
    REPLACE_FILE scratch/forge_tutorial/hello.py
    BEGIN_BODY
    name = "Forge user"
    print("Hello, " + name)
    END_BODY
    @end-forge-bundle

## EXPECT
The packet should show:

    APPLIED | REPLACE_FILE | scratch/forge_tutorial/hello.py

Run Step 3 again if you want to confirm the new output.

## STEP 5 — MOVE THE FILE
Move or rename the file.

    @forge-bundle tutorial-files-move
    MOVE_FILE scratch/forge_tutorial/hello.py
    DEST: scratch/forge_tutorial/greeting.py
    @end-forge-bundle

## EXPECT
The packet should show the old path moving to the new path.

## STEP 6 — CLEAN UP
Delete the tutorial file.

    @forge-bundle tutorial-files-cleanup
    DELETE_FILE scratch/forge_tutorial/greeting.py
    @end-forge-bundle

## EXPECT
The packet should show:

    APPLIED | DELETE_FILE | scratch/forge_tutorial/greeting.py

The empty scratch folder may remain. That is fine.

## WHAT YOU LEARNED
You have used Forge to:

- create a file
- inspect it safely
- run it
- rewrite it
- move it
- delete it

You have also seen how every action is confirmed by a run packet.
