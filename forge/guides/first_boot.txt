# first-boot

## WHEN TO USE
Use when a new AI model or a new user is starting with Forge for the first time.

## SUMMARY
Forge is a clipboard-based patching harness. The AI writes bundles, the user runs forge_entry.py, and Forge returns a run packet.

## WORKFLOW
1. The AI writes a Forge bundle.
2. The user copies it to the clipboard.
3. The user runs forge_entry.py in Pythonista.
4. Forge executes locally.
5. Forge writes the run packet back to the clipboard.
6. The user pastes the packet back to the AI.

The run packet is the source of truth.

## FIRST BUNDLE
Keep it minimal. Three ops are enough to orient.

    LIST_FILES .
    DEPTH: 2
    FILES: yes

    LIST_OPS

    GUIDE
    ARGS: list

After the packet returns, the AI knows the repo shape, the available
ops, and the available guides. That's enough to start a real
conversation about what the user wants to do.

## RULES
- Inspect before editing.
- Keep bundles small.
- One concept per teaching bundle.
- Use HELP <OP> for exact syntax. Always after a FAILED_PARSE.
- Use GUIDE for workflow patterns.
- Wait for the packet before claiming success.
