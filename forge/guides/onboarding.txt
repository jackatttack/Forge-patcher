# onboarding

## SUMMARY
Start here if you are new to Forge. Forge lets an LLM help you work on local code while you stay in control.

## WHEN TO USE
Use this when opening Forge for the first time, coming back after a break, or helping someone understand the basic workflow.

## WHAT FORGE IS
Forge is a local Pythonista development harness.

The LLM writes a plain-text bundle. You choose when to run it. Forge runs it locally and returns a run packet showing exactly what happened.

The packet is the source of truth.

## FASTEST START
Use the top-level installer if you want the easiest setup:

    install_forge.py

Create that file in Pythonista, paste the installer script from the public repo, and run it. It downloads Forge from GitHub and installs it into a clean local folder.

Then:

1. Open Forge/forge_entry.py in Pythonista.
2. Run it once.
3. LinkOS should render at the bottom of the console.
4. Tap Start if available, or manually copy docs/AI_FIRST_BOOT.txt.
5. Paste that guide into an LLM.
6. The LLM will give you a small runnable Forge bundle.
7. Copy that bundle, run forge_entry.py, and paste the returned packet back.

If your first run shows a failed parse because your clipboard did not contain a Forge bundle, that is fine. The first run is mostly there to show LinkOS and prove the install opens.

## MANUAL START
If Start cannot copy automatically, manually copy the contents of:

    docs/AI_FIRST_BOOT.txt

Paste that text into an LLM. Do not run it as a Forge bundle.

## THE BASIC LOOP
1. The LLM gives you a Forge bundle.
2. You copy the bundle.
3. You run forge_entry.py or your Forge Shortcut.
4. Forge executes the bundle on your device.
5. Forge copies a run packet back to your clipboard.
6. You paste the packet back into the chat.
7. The LLM reads the packet and decides the next safe step.

Nothing is confirmed until the packet comes back.

## CONTAINED MODE
Forge works out of the box in contained mode.

Contained mode means Forge works inside its own install folder. This is safest for first use, tutorials, and testing.

In contained mode, LinkOS still renders. Some console buttons may be display-only because Pythonista cannot always resolve deep nested launcher links reliably. That is okay: you can still run forge_entry.py manually.

## ROOT LAUNCHER MODE
Root launcher mode is optional.

It installs tiny launcher files at Pythonista Documents root. This enables tappable LinkOS links, easier Shortcut setup, and wider workspace access.

It is more powerful, so it should be deliberate.

Use [[root-launcher-mode]] when you want those benefits.

- Inspect before editing.
- Keep bundles small.
- Wait for run packets.
- Correct mistakes from packets instead of guessing.
- Use HELP before unfamiliar ops.
- Use DOCS for onboarding and workflow guidance.
- Use BRANCH before risky edits.
