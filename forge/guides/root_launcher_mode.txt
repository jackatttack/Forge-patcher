# root-launcher-mode

## SUMMARY
Forge has two launch modes. Contained mode is the safe default. Root launcher mode is an optional power upgrade that enables tappable LinkOS links and wider Pythonista workspace access.

## WHEN TO USE
Use this when the user understands the Forge packet loop and wants Forge to work across their wider Pythonista Documents folder.

## THE SIMPLE VERSION
Forge works immediately in contained mode.

In contained mode:

- forge_entry.py runs from inside the Forge install folder
- LinkOS renders after runs
- docs, HELP, LIST_FILES, and tutorials work
- tappable LinkOS console links may be display-only
- Forge can only work inside the install folder

That is the safest first experience.

Root launcher mode is optional.

In root launcher mode:

- tiny launcher files live at Pythonista Documents root
- LinkOS buttons become tappable through pythonista3:// links
- Forge can see and work across the wider Documents workspace
- Shortcuts are easier to wire to one stable root script

## WHY LINKS NEED A ROOT ROUTER
LinkOS does not need root to render.

The issue is Pythonista console links. A printed link like:

    pythonista3://linkos.py?action=run&argv=home

needs Pythonista to find a script. A root-level linkos.py is the most reliable target.

So the root router is not the real LinkOS. It is a tiny launcher that routes taps back into the Forge install.

## INSTALLING ROOT ROUTER MODE
Run this file manually from the Forge install folder:

    install_root_router.py

It creates or replaces these files at Pythonista Documents root:

    forge_entry.py
    linkos.py

Existing files are backed up first under:

    archive/forge_root_router_before_<timestamp>/

After that, run root forge_entry.py.

## RISK
Root launcher mode gives Forge broader workspace access.

That is powerful and convenient, but it means a bad bundle could affect more files. Keep using the packet loop properly:

- inspect before editing
- keep patches small
- use BRANCH before risky edits
- trust the run packet, not assumptions

## RULE FOR AI ASSISTANTS
Do not pressure the user into root mode.

Contained mode is valid. Explain root mode only when the user wants tappable links, Shortcut convenience, or wider project access.

Always infer the active root from the packet:

    LIST_FILES .
    DEPTH: 2
    FILES: no

The packet decides what Forge can currently see.
